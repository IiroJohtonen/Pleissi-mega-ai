# Kiito V1 implementation map

Source: Kiito – tuotespeksi V1.

Implemented in this MVP:
- Ticket-based core model
- Company-specific data isolation at query/model level
- Incoming email/portal/quick-note API
- Resident and apartment matching
- Emergency detection and routing state
- Ticket type and priority
- AI recommendation + draft
- Decision queue
- AI / human / skip decision actions
- Message history
- Audit trail
- Company-specific knowledge base
- Knowledge-grounded self-service draft behavior
- Basic dashboard, ticket list and knowledge views

Not implemented yet:
- Real mailbox integration
- Resident portal authentication
- Real phone/AI calling
- Property-management system integrations
- Attachments and image handling
- Real outbound email provider
- Production auth/RBAC
- GDPR operational controls
- DPIA/DPA workflow
- Full multi-company admin UI
- Scheduled follow-ups
- Daily/weekly/monthly reporting
- Mobile app
